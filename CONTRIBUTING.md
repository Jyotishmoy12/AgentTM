# Contributing to AgentTM

Bug reports, feature suggestions, documentation fixes, and pull requests are
welcome. AgentTM is a public repository with a [proprietary license](LICENSE),
not an open-source project.

## Report an issue

Include your operating system, AgentTM version, whether you use the desktop app
or CLI, reproduction steps, expected behavior, and actual behavior. Remove
credentials, private paths, prompts, recordings, and raw agent output before
posting. Use a disposable Git repository for reproduction when possible.

## Submit a pull request

1. Read section 3 of [LICENSE](LICENSE). It permits local builds, modifications,
   testing, and GitHub forks for contributing to AgentTM.
2. Discuss substantial changes in an issue first. Keep fixes small and focused.
3. Fork the repository, make your changes on a branch, and follow the
   [development guide](docs/development.md).
4. Run checks appropriate to the change and describe their actual results in
   your pull request. Include screenshots for UI changes and identify anything
   you could not test. Never test destructive actions against real user history.
5. Submit the pull request to the official repository. Maintainers review it
   before inclusion; submission does not guarantee acceptance.

Only submit work you have the right to contribute. Identify third-party code and
its license. Under section 3, you retain copyright in your contribution and grant
the maintainer permission to incorporate, modify, distribute, sublicense, and
sell it as part of AgentTM. This is not a copyright assignment.

## What contribution permission does not allow

It does not allow selling AgentTM or a modified copy, publishing it as your own
product, rebranding its implementation, or offering it as a hosted service.
Separate written permission is required for those uses. GitHub's platform rights,
applicable law, third-party licenses, and existing grants remain unaffected.
