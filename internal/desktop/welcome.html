AGENTTM · WORKSPACE HISTORY

Open your project

Record Codex activity, inspect workspace changes, and restore checkpoints into a separate working copy.

  1. Choose an existing Git project folder.
  2. If it is new to AgentTM, confirm creation of local history.
  3. Explore your dashboard or set up Codex to start recording.

Git must be installed. AgentTM stores history in the project's .agenttm folder and adds a local Git exclusion. It does not create a commit. Codex is needed for new recordings, but not for inspecting saved history.
